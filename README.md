# Groundwork

Groundwork helps entrepreneurs answer two critical questions:

1. Where should I open my business?
2. How should I fund it?

Features:
- Neighborhood opportunity analysis
- Demographic insights
- Competition analysis
- Funding eligibility matching
- Business launch planning

Tools:
- Figma
- Market Research
- User Journey Mapping
- Product Strategy
